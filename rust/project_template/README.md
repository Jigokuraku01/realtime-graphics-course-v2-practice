# Домашнее задание 1: планетная система

Из каталога `rust` запустите:

```sh
cargo run -p project_template
```

При каждом запуске создаётся новая система: Солнце, от 4 до 8 планет, случайное
число спутников у каждой, несколько наклонённых колец у двух или трёх планет,
свечение Солнца и звёздное небо. На кольцах видна тень планеты.
Размеры, цвета, рисунок поверхности и параметры орбит тоже меняются.
Планеты и спутники не выбираются из готового списка видов. Значения выбраны
для наглядности, а не для астрономической точности.

## Управление

- Движение мыши — поворот камеры.
- `W`/`S` — вперёд/назад; `A`/`D` — влево/вправо.
- Стрелки вверх/вниз тоже двигают вперёд/назад.
- `Пробел` — пауза или продолжение анимации. Камера остаётся подвижной.
- `Esc` — отпустить курсор; щелчок левой кнопкой — снова захватить.

При переключении на другое окно нажатые клавиши сбрасываются, а курсор
освобождается. После возвращения в окно щёлкните левой кнопкой, чтобы снова
управлять камерой мышью.

Курсор захватывается при первом кадре, чтобы можно было свободно вращать
камеру. При изменении размера окна обновляются проекция и буфер глубины.

## Структура

- `main.rs` — параметры окна и запуск `WgpuApp`.
- `renderer.rs` — обработка ввода и времени, создание проходов кадра.
- `camera.rs` — положение и ориентация камеры, матрица вида и проекции.
- `mesh.rs` — общая индексированная icosphere и геометрия колец.
- `colors.rs` — процедурный рисунок поверхности из индивидуальных цветов и
  параметров узора; цвета Солнца пересчитываются на CPU и загружаются на GPU
  каждый кадр.
- `system_generator.rs` — случайные параметры тел, их внешности и иерархии. Использует
  `rand::rngs::StdRng` с seed для воспроизводимой генерации.
- `solar_system.rs` — тела, орбиты, вращения, общие GPU-ресурсы, буферы
  цветов каждого тела и pipelines. Модель каждого тела строится одной
  матрицей из перемещения, наклона, вращения и масштаба.
- `body.wgsl` — Солнце без освещения и планеты с освещением от центра сцены.
- `ring.wgsl` — двусторонние кольца с освещением и тенью от планеты,
  а также полупрозрачное свечение Солнца.
- `starfield.rs`, `stars.wgsl` — 2000 случайных звёзд на единичной сфере;
  генерация использует `rand::rng()`. Звёзды рисуются одним instanced draw
  до остальных объектов, без теста глубины.
  Для звёзд используется только поворот камеры, поэтому перемещение неба
  не меняет.

Общий crate `wgpu_app` из этого репозитория создаёт окно, `Device`, `Queue` и
`Surface` и передаёт их через `app: &WgpuState`.
